- Environment-variable tutorial (verified 2026-10-23): django-environ read_env defaults to overwrite=False; existing process variables win. Explicit overwrite=True reverses that policy. env.bool parses DEBUG, and a required SECRET_KEY raises ImproperlyConfigured when missing. A .env is plain text and ignore rules do not remove tracked secrets. Sources: https://django-environ.readthedocs.io/en/stable/api.html#environ.Env.read_env, https://django-environ.readthedocs.io/en/stable/faq.html, https://docs.djangoproject.com/en/5.2/howto/deployment/checklist/. Abstract bases create no table; auto_now does not run for omitted update_fields or QuerySet.update(). UUIDs do not replace object authorization or a database uniqueness constraint. Sources: Django 5.2 abstract-model, authentication, instance-save and queryset-update references; extracted snippets tested on Python3.11/Django5.2.18/SQLite with default and configured custom users. No production migration or authorization audit.
